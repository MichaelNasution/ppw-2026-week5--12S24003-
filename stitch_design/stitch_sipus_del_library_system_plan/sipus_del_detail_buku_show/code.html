Sinopsis & Ruang Lingkup Materi

Buku teks ini disusun secara terpadu guna memperkuat pemahaman fundamental mahasiswa program studi S-1 Informatika dan Sistem Informasi Institut Teknologi Del terhadap struktur pengorganisasian data dalam memori komputer dan perancangan algoritma pemrosesan yang mangkus. Melalui pendekatan pragmatis berbahasa Python versi 3, pembaca dituntun menelaah representasi abstrak (Abstract Data Type) mulai dari senarai bertaut (linked list), tumpukan (stack), antrean (queue), hingga struktur non-linear kompleks berupa pohon biner terurut (binary search tree) dan graf.

Setiap bab diperkaya dengan analisis kompleksitas asimtotik Big-O (waktu komputasi dan ruang memori), teknik perancangan algoritma serakah (Greedy), pendekatan rekursif, strategi Divide and Conquer, serta pemograman dinamis (Dynamic Programming). Monograf ini menjadi rujukan utama modul praktikum laboratorium rekayasa perangkat lunak di kampus Laguboti.

Kata Kunci Subjek: Python Programming Algoritma Asimtotik Pohon Biner & Graf Kompleksitas Big-O
